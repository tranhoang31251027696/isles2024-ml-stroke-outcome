# Public pipeline outputs

This directory mirrors the V3 analytical stages with publication-relevant, aggregate outputs:

- stage protocols and completion records;
- aggregate performance, calibration, decision-curve, sensitivity, centre, and literature-comparator tables;
- reproducibility and privacy-audit summaries; and
- generated figures.

It intentionally excludes individual-level out-of-fold predictions, fold assignments, missing-cell masks, checkpoint files, trained model objects, and raw or derived clinical data. Run the pipeline locally with the source data to regenerate the complete private working outputs.
