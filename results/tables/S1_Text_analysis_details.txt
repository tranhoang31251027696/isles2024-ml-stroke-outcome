GBM uses one fixed configuration: 150 trees, depth 2, learning rate 0.05, subsample 0.8 and no class weighting. The seven other families each have six structures crossed with two weighting modes (12 candidates). The fixed primary configuration was retained after inspecting exploratory results on this cohort, not specified before data analysis. Imputation, scaling and class weights are fitted within each training partition. All 22 predictors are retained. No feature reduction filter is used. All validation probabilities refer to unfavorable outcome. Clinical score components use training-mode imputation for binary variables and training-median for Age/NIHSS. THRIVE uses age cutpoints 60/80, NIHSS cutpoints 11/21 (0/2/4 points) and one point each for hypertension, diabetes and atrial fibrillation. SPAN-100 is the binary indicator Age+NIHSS >=100. Clinical calibration is L2 logistic regression, C=1, fitted on outer training only. Missingness-only LR and procedural-variable comparisons use the same outer folds.

Auxiliary GBM search (post-review)

An auxiliary GBM search evaluated six tuples of (n_estimators, max_depth, learning_rate, subsample), each crossed with unweighted and training-balanced fits, yielding 12 candidate pipelines. The fixed primary configuration, (150, 2, 0.05, 0.8) with unweighted fitting, was included in this grid. ROC AUC was used for selection in the same three inner folds; preprocessing was refitted within each inner-training split, and the selected pipeline was refitted on the outer-training set. This auxiliary search is distinct from the historical screening analysis.
